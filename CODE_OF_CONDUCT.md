# Code of Conduct

## Our standard

This project is technical and evidence-driven. Disagreement is welcome; contempt
is not. Concretely, contributors must:

1. **Argue with evidence, not authority.** "It does not reproduce on my machine"
   is a valid answer; "trust me" is not.
2. **Criticise the artifact, not the person.** A failing test is not an insult.
3. **Do not fabricate.** Claiming a check passed when it did not is the one
   unrecoverable offence in this repository — see `CONTRIBUTING.md`.
4. **Respect confidentiality.** Do not paste secrets, tokens or private data into
   issues or pull requests. Report vulnerabilities privately instead
   (`SECURITY.md`).

Unacceptable behaviour: harassment, personal attacks, discriminatory language,
doxxing, sustained disruption, or deliberately wasting reviewers' time with
claims that were never tested.

## Scope

Applies to issues, pull requests, discussions, commit messages and any space
where someone represents this project.

## Enforcement

Report problems to the maintainer listed in `SECURITY.md`. Responses escalate:
a private clarification → a public correction → temporary ban → permanent ban.
Enforcement decisions are recorded in the issue that triggered them, because
this repository documents its decisions.

## Attribution

Adapted in spirit from the Contributor Covenant v2.1, reduced to what this
project can honestly enforce with a single maintainer.
