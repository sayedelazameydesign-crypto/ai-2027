# Static launch announcement — AI-2027

## Short version (EN)

AI-2027 is launching its static site and interactive demo.

The project is an evidence-first agent ecosystem: deterministic execution, policy checks before action, independent verification after action, and SHA-256 evidence records for what actually happened.

Try the browser demo: https://sayedelazameydesign-crypto.github.io/ai-2027/demo.html

Honest scope: the browser demo is a labelled JavaScript port, not the Python kernel and not an LLM. The archive contains 48 projects, including `new-agent`, which is excluded from this launch pending a license decision. Only one project is proven by execution in the audit; the rest are declared, simulated, or failed inspection. Only projects that specify MIT or Apache-2.0 are open source. The live Python agent service is not part of this static launch.

Repo: https://github.com/sayedelazameydesign-crypto/ai-2027

## Longer version (EN)

AI-2027 is an evidence-first agent ecosystem. The core idea is simple: an agent should not just claim it did something — it should produce a verifiable record.

The deterministic kernel separates planning, policy, execution, verification, evidence, and reporting. Policy can deny an action before it runs. An independent verifier re-reads the resulting state. Failures are reported as failures, not dressed up as success.

This launch is static: GitHub Pages hosts the site and the interactive browser demo. The browser demo is explicitly a JavaScript port for exploration; it is not the Python kernel and it does not call an LLM.

The archive contains 48 projects, including `new-agent`, which is excluded from this launch pending a license decision. Only one project is proven by execution in the audit; the rest are declared, simulated, or failed inspection. Only projects that specify MIT or Apache-2.0 are open source.
