## 2️⃣ المسارات (Tracks) — مرتّبة حسب الأهمية

### 🔴 T1 — الاستمرارية والاشتعال الذاتي `[منفّذ الآن]`
- `.github/workflows/ember.yml`: نبضة كل 6 ساعات + تشغيل يدوي.
- `scripts/ember_beat.py`: يشغّل الفحص الحقيقي، يحسب الحرارة، ينشر الحالة، ويفشل بصدق.
- `heartbeat` branch: سجل النبضات (وقود بقاء الجدولة نفسها).
- **معيار القبول:** `gh run list --workflow ember.yml` يُظهر تشغيلات بلا بشر؛ و`gh workflow view ember.yml` = `active`.
- **القيد المعلن:** جدولة GitHub تتعطل بعد ~60 يومًا بلا نشاط → كوميت النبضة هو الحل.

### 🟠 T2 — الطبقة الآلية: الاكتشاف والقياس `[منفّذ الآن]`
- `agent-card.json` (A2A-style) + `GET /api/agent-card` + `GET /api/metrics` (Prometheus نصي).
- البطاقة تُعلن **حدودها** لا مهاراتها فقط (`honest_limits`)، وهذا مُختبَر في الفحص.
- **معيار القبول:** `/api/agent-card` يعيد كل نقاطه بادئة بـ`/api/`، و`ai2027_runs_total{status="VERIFIED"} >= 1`.

### 🟡 T3 — جودة الاسترجاع (أهم فجوة هندسية باقية) `[مخطّط — Q1 2027]`
الواقع: 16/16 على مفردات المدونة، **2/16 على إعادة الصياغة**. هذا ليس عيبًا مخفيًا، بل **رقم منشور**.
خطة الرفع بترتيب التكلفة/الأثر:
1. **معجم مرادفات مُعلن** (40–60 مدخلًا يدويًا) + تطبيع لاحقات (stemming خفيف) + ترجيح IDF + شرط تغطية (≥ مفهومين) — **بلا أي تبعية**.
2. **إعادة قياس كاملة** على نفس مجموعات `memory/evaluate.py` (سهل/صعب/سلبي/شبه-سلبي)، ورفض أي تحسين يرفع الإيجابيات الكاذبة.
3. **تضمين محلي اختياري** (sentence-transformers) خلف راية صريحة `--neural`، مع بقاء المسار الافتراضي صفر-اعتماديات.
- **معيار القبول:** `hard_recall@3 ≥ 0.60` **مع** `near_miss_false_positive_rate = 0` — وإلا يُرفض التغيير.
- **لماذا ليس الآن؟** لأنه يمسّ بوابة اختبار مقصودة (`test_11_paraphrase_is_missed_honestly`)؛ تغييرها يحتاج إعادة قياس كاملة، لا ترقيعًا.

### 🟢 T4 — الاستمرارية عبر مزوّدين `[مخطّط — Q1–Q2 2027]`
| المسار | اليوم | المطلوب |
|---|---|---|
| GitHub Pages | ✅ حيّ | — |
| حزمة محلية بأمر واحد | ❌ | `scripts/ember_up.sh` + اختبار على آلة نظيفة |
| مرآة ثانية (Vercel/Netlify) | Vercel موصول · **0 مشاريع** | قرار المالك: إنشاء مشروع |
| Supabase (حالة/سجلات) | موصول، غير مستخدم | جدول `beats` للقراءة الخارجية |
- **معيار القبول:** ثلاثة مصادر تعطي `200` لنفس المحتوى؛ وسقوط أي مسار لا يخفض الحرارة أكثر من 0.07.

### 🔵 T5 — المراقبة والاستجابة `[مخطّط — Q2 2027]`
- `health_gate.py`: يقارن النبضة بالسابقة ويرفض التدهور الصامت.
- تصعيد بثلاث درجات: نبضة فاشلة → إعادة محاولة → issue → (اختياري) تنبيه خارجي.
- **معيار القبول:** كسر متعمّد ⇒ issue خلال نبضة واحدة ⇒ إغلاق تلقائي بعد الإصلاح (مُختبَر بـ`workflow_dispatch`).

### 🟣 T6 — المنتج نفسه (ما يجعل المشروع ذا معنى في 2027) `[مخطّط — Q2–Q3 2027]`
المستودع اليوم «مُبرهِن» أكثر من كونه «مُنتجًا». التسليمات المقترحة:
1. **واجهة تشغيل حقيقية**: من صفحة ثابتة إلى صفحة تُشغّل مهمة فعلية على سيرفر حقيقي وتُظهر الدليل (`run_id` + التنزيل).
2. **مخطط قابل للاستبدال**: العقد `Planner` موجود؛ إضافة مخطط LLM اختياري مع تسجيل القرارات وأسبابها.
3. **سياسة قابلة للتحرير**: قواعد الحظر (traversal، حجم، مسارات) من ملف إعدادات موقّع، مع اختبار انحدار لكل قاعدة.
- **معيار القبول:** مستخدم خارجي يُنجز مهمة كاملة في <60 ثانية، وكل نتيجة تحمل رابط دليل.

## 5️⃣ مؤشر الحرارة (Heat Index) — التعريف المنفّذ

```
HEAT = 0.4×success_rate_7d
     + 0.2×(1 − min(أسوأ فجوة/24س, 1))
     + 0.2×(min(ذكريات,100)/100)
     + 0.2×(مسارات حيّة/3)
```

- **≥ 0.8** مشتعلة · **0.5–0.8** ساخنة بلا لهب · **< 0.5** تنطفئ.
- «أسوأ فجوة» = الأكبر بين أطول صمت داخل النافذة والزمن منذ آخر نبضة ⇒ **الصمت يُحسب بردًا دائمًا**.
- مُختبَر: `test_03` يُثبت أن أسبوعًا من الصمت لا يمكن أن يبدو صحيًا مهما كانت الذاكرة.
