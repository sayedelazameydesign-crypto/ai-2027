# حماية Studio بتسجيل Google — تجهيز غير منشور

## الحالة وحدودها

أضيف مسار اختياري لمصادقة Studio في `python-2027`، وهو **معطّل افتراضيًا** حفاظًا على توافق النشر القديم. لا تعتبر الخدمة محمية ما لم يُضبط `AI2027_STUDIO_AUTH_MODE=google` وتنجح الاختبارات الحية أدناه. لم يُعدّل `render.yaml` ولم تُغيّر خدمة Render أو Google Cloud، ولم تُربط Gmail. اختبارات الكود تستخدم Google محاكى، وليست إثباتًا لتشغيل Google أو Render الحقيقي. قبل أي بيانات حساسة يُنصح بمراجعة أمنية مستقلة وبتقييد الخدمة من لوحة الاستضافة أو بوابة هوية إلى حين الانتهاء.

عند اختيار وضع `google`، يفشل بدء التطبيق إذا غاب إعداد ضروري. يحمي middleware كل مسارات التطبيق، بما فيها الواجهة والبحث والقراءة وواجهة OpenAPI؛ الاستثناءات العامة الوحيدة هي `GET /auth/login` و`GET /auth/callback` و`GET /auth/health` (استجابة صحية بسيطة). يعيد API غير المصادق 401؛ ويُرفض الحساب غير الموجود في قائمة السماح أو غير المؤكد من Google بـ403. طلبات التغيير تحتاج رأس `Origin` مطابقًا للأصل المكوَّن. المصادقة تستخدم authorization code مع PKCE وstate وHTTPS إلى Google، ثم تفحص البريد المؤكد من واجهة Google userinfo؛ النطاقات المطلوبة هي `openid email` فقط، **وليست** صلاحيات Gmail. لا يُخزن رمز Google في جلسة المتصفح.

الجلسة cookie موقّعة، `Secure` و`HttpOnly` و`SameSite=Lax`، تنتهي بعد ساعة. محتواها قابل للقراءة، وليس مشفّرًا. تسجيل الخروج عبر `POST /auth/logout` يحذف cookie من المتصفح فقط؛ لا يبطل نسخة مسروقة على الخادم. لتبطال جميع الجلسات غيّر مفتاح التوقيع وأعد تشغيل الخدمة. لا يوجد حالياً إبطال جلسات فردية على الخادم أو تحديد معدل للطلبات أو تدقيق مستقل. مدة الجلسة لا تعكس فورًا إلغاء وصول الحساب لدى Google. لا تعتمد عليها قبل تقييم هذه الحدود وفق احتياجات الإنتاج.

## تجهيز Google وRender

1. حدّد نطاق Studio الفعلي بدقة؛ اسم الخدمة في `render.yaml` لا يثبت رابطها الفعلي أو حالة تشغيلها. استخدم HTTPS. لا تستخدم الرابط الافتراضي في هذا المستند كقيمة فعلية.
2. في Google Cloud Console، أعد شاشة الموافقة واختبار المستخدمين وفق حالة مشروعك. أنشئ OAuth Client من نوع **Web application**، وسجّل Authorized redirect URI مطابقًا تمامًا لـ`https://<studio-domain>/auth/callback`. تحقق أن حسابك ضمن مستخدمي الاختبار إذا كان المشروع في وضع Testing. احتفظ بسر العميل خارج Git والمحادثة.
3. جهّز القيم في إعدادات البيئة الآمنة لـRender، وليس في الكود أو سجل عام:
   - `AI2027_STUDIO_AUTH_MODE=google`
   - `AI2027_GOOGLE_CLIENT_ID` و`AI2027_GOOGLE_CLIENT_SECRET` من عميل Google نفسه.
   - `AI2027_GOOGLE_REDIRECT_URI`: رابط callback HTTPS الدقيق المسجل أعلاه.
   - `AI2027_STUDIO_ALLOWED_EMAIL`: حساب Google المصرح الوحيد (مثلاً `sayedelazameydesign@gmail.com` إذا كان هو المقصود).
   - `AI2027_STUDIO_SESSION_KEY`: 32 بايت عشوائيًا على الأقل بترميز URL-safe base64. ولّده محليًا مثل `python -c 'import secrets; print(secrets.token_urlsafe(32))'` وضع الناتج مباشرة في مخزن أسرار Render، ولا ترسله في المحادثة أو Git.
4. عند تفعيل المصادقة اضبط فحص صحة Render على `/auth/health` بدل `/v1/studio/status` المحمي. جهّز جميع القيم ومسار الفحص في النشر نفسه؛ لا تعتمد على النشر التلقائي غير المراجع. لا تُفعّل وضع `off` كحل لمشكلة إعداد.
5. يعطّل مشغّل CLI سجلات وصول Uvicorn حتى لا يسجل رمز callback. تحقّق أيضًا من عدم تسجيل query string أو ملفات الارتباط في Render وأي proxy أو خدمة مراقبة أمامه؛ التطبيق وحده لا يتحكم بسجلاتها. لا تضف بيانات اعتماد Gmail الآن.

## التحقق بعد النشر — لم يُنفّذ هنا

- افتح `/studio` من نافذة خاصة: يجب التحويل لتسجيل الدخول. طلب مباشر دون cookie لـ`/v1/studio/status` و`/v1/studio/connectors/read` وبقية API يجب أن يُرفض بـ401؛ `/auth/health` فقط عام من أجل الفحص الصحي.
- سجّل دخولًا بحساب Google آخر ومؤكد: يجب رفضه بـ403 وعدم منحه جلسة. اختبر الدخول بالحساب المسموح والتحقق من API والواجهة. اختبر `POST` من أصل آخر وأنه يرفض بـ403، ثم اختبر تسجيل الخروج وإعادة الرفض.
- افحص جميع النطاقات البديلة والخدمات والأصول الخلفية حتى لا يوجد نشر قديم أو مسار بديل يتجاوز المصادقة. افحص سياسة الشبكة والسجلات وHTTPS والتخزين والنسخ الاحتياطية، وحدد احتفاظ الجلسات/المحتوى وحماية المدخلات الخارجية من حقن التعليمات.
- بعد نجاح هذه الاختبارات ومراجعة الخصوصية فقط: صمّم ربط Gmail منفصلًا بـ`gmail.readonly` وتجديد آمن للرموز؛ موصل Arena لا يسلّم اعتماده لـStudio، وعميل Studio لا يملك حاليًا تنفيذ بحث/قراءة Gmail. لا إرسال أو حذف أو أرشفة آلية. أي تعديل حساس يظل مشروطًا بموافقة صريحة لكل إجراء.
