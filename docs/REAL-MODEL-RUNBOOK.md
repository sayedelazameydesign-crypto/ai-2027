# دليل تشغيل نموذج حقيقي — من الصفر إلى رقم

**الغرض:** شخص يملك Ollama (أو مفتاح API) يحصل على رقم جودة مقارَن بخط الأساس في **أقل من خمس دقائق**، دون قراءة كود.

**خط الأساس المرجعي:** `0.5783` (القالب الحتمي، 24 جملة ثابتة، 8 مجالات).

---

## 1. المسار الأسرع — Ollama محلي (مجاني، بلا مفتاح)

```bash
# 1. ثبّت Ollama ثم اسحب نموذجًا صغيرًا
ollama pull qwen3.5:0.8b

# 2. تأكد أنه يعمل
curl -s http://127.0.0.1:11434/api/tags

# 3. قِس
cd /path/to/ai-2027
python3 scripts/run_real_model.py --ollama http://127.0.0.1:11434 --model qwen3.5:0.8b
```

المخرَج المتوقع:

```
checking ollama at http://127.0.0.1:11434 ...
connected · model=qwen3.5:0.8b · 412 ms
measured 24 sentences · mean=0.7xxx usable=xx% complete=100%
report: fleet-2027/bench/model.json

baseline (scaffold) 0.5783 -> model 0.7xxx (+0.xxxx)
RESULT: ...
```

## 3. كيف تقرأ النتيجة

| المخرَج | المعنى | القرار |
|---|---|---|
| `RESULT: the model beats the scaffold` | الفرق > 0.02 | ✅ أرسل |
| `RESULT: indistinguishable` | الفرق ≤ 0.02 | ⚠️ لا تدّعِ تحسّنًا |
| `RESULT: the model is WORSE` | الفرق < −0.02 | ❌ حقّق قبل الإرسال |

**قد يُخرج السكربت `exit 2` بلا رقم.** هذا مقصود، وله أربعة أسباب فقط:

| السبب | الرسالة |
|---|---|
| لا endpoint | `refusing to run: … is not reachable` |
| لا مفتاح | `refusing to run: LLM_API_KEY is not set` |
| لا يوجد أي استدعاء نموذج في الدليل | `refusing to report: no step recorded a model call` |
| مسار إخراج خارج المستودع | تُطبع القيمة كما هي، لا استثناء |

في كل حالة: **لا رقم، ولا ادّعاء**. هذا أفضل من رقم مبني على قالب يحمل اسم نموذج.

## 7. ما أُثبِت بلا نموذج حقيقي

في البيئة التي بُني فيها هذا، **لا مفاتيح ولا أوزان ولا وصول لـHuggingFace**. ما أُثبت مع ذلك:

| ما أُثبت | كيف |
|---|---|
| مسار Ollama يعمل عبر HTTP حقيقي | `FakeOllamaServer` على socket فعلي، `OllamaBackend` نفسه |
| الـprompt يصل من الخطة إلى النموذج | الخادم يسجّل الطلب، والاختبار يؤكد وجود النص العربي |
| `model_called` مشتق من دليل الخطوة | `test_a_model_call_is_recorded_in_evidence` |
| العدّاد يرفض رقمًا بلا استدعاء | `refusing to report: no step recorded a model call` |
| الأدوات ترفض عند غياب الشرط | أربعة مسارات `exit 2` مُختبرة |

**ما لم يُثبت، ولا أدّعيه:** أن أي نموذج حقيقي يحصل على رقم معين.

## 6. تشغيله من GitHub Actions (الطريق الذي يعمل اليوم)

`run_real_model.py` يحتاج مفتاحًا حقيقيًا. المفتاح موجود في أسرار المستودع، لا في هذه البيئة.
لذلك الطريق العملي هو **workflow** لا صدفة:

```bash
gh workflow run real-model.yml -f model=openrouter/free      # يدويًا
# أو تلقائيًا عند تغيّر bench/** أو السكربت على main
```

**ما يفرضه الملف، لا ما يوعده:**

| القاعدة | كيف تُفرَض |
| --- | --- |
| `main` فقط | خطوة أولى تُفشل أي مرجع آخر |
| صفر إنفاق | السكربت يرفض أي نموذج ليس `openrouter/free` أو `*:free` **قبل** أي اتصال |
| لا أسرار في السجلات | المفتاح عبر `env:` فقط؛ يُطبع اسم النموذج والزمن لا غيرهما |
| الرفض ليس نجاحًا | `exit=2` (مفتاح غائب/نموذج مدفوع/غير متاح) → الوظيفة تفشل بصوت عالٍ |
| الحكم مفهوم | المقارنة بـ0.5783 تظهر في صفحة الوظيفة، والتقرير يُرفع كـartifact |

**خطأ وجدته وأنا أبني هذا:** نسختي الأولى كتبت `echo "exit=$?"` بعد `tee`، فقرأت **حالة `tee`** لا حالة السكربت — أي أن رفضًا كان سيبدو نجاحًا. أصلحته بـ`${PIPESTATUS[0]}`، وهذا الفخ موثّق أصلًا في سجل أخطاء المشروع.

**حدّ الصدق:** لم يُنتَج رقم نموذج حقيقي بعد. الملف والسكربت مُختبَران محليًا (رفض نموذج مدفوع → `exit 2` → فشل وظيفة؛ غياب مفتاح → `skipped` أو فشل عند `require_live`)، لكن **تشغيل `openrouter/free` الأول سيحدث في Actions، وسأقرأ نتيجته من هناك لا من هنا.**

## 7. سجل التشغيل الحقيقي على GitHub Actions (2026-11-20)

تسع جولات على `main`. كل جولة استبعدت سببًا أو أثبتت مكوّنًا. **لا رقم في نهاية الجدول، وهذا مقصود.**

| # | ما جرى | الدليل المقروء |
| --- | --- | --- |
| 1-2 | فشل صامت | لا سجل ولا ملخص ولا artifact مقروء (blob storage) |
| 3 | المفتاح؟ | `key present: True · length: 73 · prefix ok: True` |
| 4 | الشبكة؟ | `dns ok · tls 1.3 ok · GET /api/v1/models: http 200` |
| 5 | حد المعدل؟ | 3 نماذج `:free` بالتناوب |
| 6 | شكل الردّ؟ | `finish_reason='length'`, `top_level_keys=[...usage...]` |
| 7 | **النجاح** | كل الخطوات خضراء · `real-model-report` artifact (1661 بايت) |
| 8 | الحصة | `http_429 · X-RateLimit-Limit: 50 · Remaining: 0` |
| 9 | الرسالة صحيحة | `reachable but the free quota is exhausted: http_429` |

### الأعطال الحقيقية التي كشفتها الجولات (كلها أُصلحت)

1. **`echo "exit=$?"` بعد `tee`** — كان الرفض سيبدو نجاحًا. أُصلح بـ`${PIPESTATUS[0]}`.
2. **`"not reachable"` لكل فشل** — بما فيه ردّ وصل ولم يُفسَّر. صارت ثلاث حالات منفصلة.
3. **المسبار 8 توكنات** — نموذج تفكير يستهلكها كلها في `reasoning` ويعيد `content` فارغًا. صارت 512.
4. **`content` فارغ + `reasoning` ممتلئ** — لم يكن يُقرأ. صار يُقرأ.
5. **`finish_reason='length'`** — كان "invalid payload". صار `truncated`.
6. **اختبار يستبدل الدالة التي يختبرها** — ينجح دون أن يختبر. صار يستبدل `urlopen`.
7. **48 مسارًا في CI لا يشمل `scripts/`** — عدّلت سكربت بوابة ولم يُشغَّل CI عليه. أُضيف.
8. **عنوان يقول "9 tests" والفعل 13** — تصحيح تافه لكنه كذب صغير.

### ما يمنع الرقم الآن

```
X-RateLimit-Limit: 50 · X-RateLimit-Remaining: 0
free-models-per-day
```

حصة شهرية/يومية مجانية. تتجدد. القياس المقيّد (`--limit 8`) جاهز وينتظر رصيدًا.

**لذلك: الأنبوب يعمل مع نموذج حقيقي — مرّ من كل مرحلة حتى الـartifact. المتبقي رصيد مجاني، لا كود.**
