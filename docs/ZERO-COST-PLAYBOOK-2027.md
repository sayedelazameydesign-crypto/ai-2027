## 2. مراحل التنفيذ الأربع

### المرحلة أ — إشهار «المصداقية الهندسية» كأول ميزة تنافسية

1. **الشفافية بدل المبالغة:** في بيئة تعج بالادعاءات غير المختبرة، إبراز أن النظام يعتمد على فحص فعلي (`PROVEN` مقابل `DECLARED`/`SIMULATED`/`FAILED`) وتصحيح الادعاءات غير الموجودة يمنح تميزاً حقيقياً لدى المهندسين وأصحاب الأعمال.
2. **الأرقام المقاسة بوضوح:** ربط أي عرض تعريفي بالحقائق المثبتة (2,054 اختباراً · 100 هجوم red-team دون اختراق · 48 مشروعاً · 13 محركاً) مع الإشارة الصريحة إلى أن المشاريع أو المستودعات غير المكتملة أو الفارغة لا تُعدّ جاهزة للإنتاج.

### المرحلة ب — نشر حزمة تعريفية وتشغيلية مجانية خطوة بخطوة

1. **حزمة تعريف مختصرة (1-Page Overview):** ملخص مركّز يشرح: ما هو النظام، لماذا بُني، ما الذي يعمل حالياً (`PROVEN`)، وكيف يمكن تجربته مجاناً أو محلياً. ← موجودة: `docs/OVERVIEW-2027.md`
2. **جولة مرئية قصيرة (3 إلى 5 دقائق):** تسجيل شاشة يشرح البنية الخماسية، ولوحة الجرد، وكيف يطبق النظام قاعدة «المجانية أولاً» و«الصدق البنيوي»؛ يُنتج بالكامل محلياً بأدوات مجانية (OBS Studio) دون أي تكلفة.
3. **مسار تجربة آمن:** إتاحة اختبار أو معاينة لا تمس الملفات الأساسية (`projects/`) وتوضح بوضوح ما هو مدعوم حالياً وما هو قيد التطوير. ← موثّق في §4 أدناه.

### المرحلة ج — قنوات الإشهار والانتشار المجانية

1. **سلسلة تدوينات أو منشورات مترابطة** (مخطط §5 أدناه).
2. **إعادة تدوير المحتوى:** تحويل كل شرح أو تجربة ناجحة إلى منشور نصي مختصر، وبطاقة مقارنة سريعة، وعرض عملي قصير دون تكرار ممل.
3. **الربط المباشر بملفات التوثيق:** توجيه المهتمين إلى المراجع الموثقة في المستودع (`docs/ENGINEERING-INVENTORY-2027.md` · `docs/engineering-inventory-2027.html` · `docs/inventory-2027.json`) لمن يريد التفاصيل التقنية العميقة.

### المرحلة د — نماذج ربح تدريجية متوافقة مع «المجانية أولاً»

1. **الخدمات التطبيقية المخصصة (Done-With-You / Setup):** مساعدة عميل أو مطور في تنظيم بيئة عمل محلية، أو تطبيق بروتوكول عمل منظم، أو إعداد بنية اختبارات وتوثيق — يبدأ الاتفاق بتعريف واضح للنطاق والمخرجات.
2. **الترقيات والوحدات المخصصة:** إبقاء النواة أو الشرح العام مجانياً، وتقديم التخصيص العميق أو الربط الخاص بحالة عميل معين كخدمة مدفوعة عند الطلب.
3. **الدعم التطوعي أو الشراكات الصغيرة:** وسيلة دعم اختيارية أو تعاون عملي مباشر مع جهات أو أفراد يقدّرون الأدوات المحلية ومفتوحة المصدر — مع إبقاء التشغيل الأساسي مجانياً بالكامل في البداية.

## 4. مسار التجربة الآمن (خطوة بخطوة — $0 · لا يمس `projects/`)

```bash
# 1) استنساخ المستودع العام
git clone https://github.com/sayedelazameydesign-crypto/ai-2027.git
cd ai-2027

# 2) فتح لوحة الجرد في المتصفح (لا خادم، لا تثبيت)
#    افتح الملف مباشرة: docs/engineering-inventory-2027.html

# 3) إعادة إنتاج جرد الـ48 مشروعاً (قراءة-فقط)
python3 command-hud/audit.py

# 4) إعادة إنتاج اختبارات النواة الحتمية
python3 -m unittest discover -s projects/agi-system/tests -t projects/agi-system

# 5) إعادة إنتاج فحص الأمان (100 هجوم)
python3 command-hud/redteam.py --markdown

# 6) قراءة البرومبت العمومي الجاهز للنسخ
#    docs/ENGINEERING-INVENTORY-2027.md — القسم §9
```

**ما يدعمه هذا المسار:** التحقق من كل رقم في الجرد، وتجربة النواة الحتمية، وفحص الأمان — كلها محلياً وبصفر تكلفة.
**ما لا يدعمه:** تشغيل مشاريع Node المؤرشفة (تحتاج `npm ci` وشبكة) — تبقى `DECLARED` حتى تُنفَّذ.
