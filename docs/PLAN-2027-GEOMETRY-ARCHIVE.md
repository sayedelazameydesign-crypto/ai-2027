## 1. المبادئ

1. **لا رقم بلا قياس**؛ كل معيار أدناه رُقّم من تشغيل فعلي.

4. **المسطرة تُختبر بمُدخَل عدائي.** أي مسطرة تُمرّر صفحة فارغة لا تُصلح بتمرير سقالة.

## 4. المرحلة C — الطبقة 4 (تنفيذ/تحويل/تحرير)

`coverage = {compile: 0, patch: 1, ...}` اليوم — **`compile` صفر**، و`patch` معلن بلا اختبار تلف.

### C1. عقد التحرير الآمن
| القاعدة | المعيار |
|---|---|
| لا كتابة في المكان | الأصل يُفتح `"rb"` فقط؛ الناتج `<file>.new` |
| الأصل ثابت | `sha256` قبل == بعد |
| الفرق مرئي | unified diff بعدد أسطر `+`/`-` |
| فشل بلا أثر | patch فاشل ⇒ **لا** `.new` |

### C2. `compile` من 0 إلى 1
أول قدرة حقيقية: **CSV → parquet** (جدولي، بلا مكتبة) أو **STEP → STL**.
| القبول | الرقم |
|---|---|
| `coverage['compile']` | **≥ 1** |
| تحويل ناجح | `sales.csv 1,024 B → sales.parquet 718 B` |
| تحويل فاشل | سبب صريح، **لا ملف ناتج** |

### C3. `patch` مُثبَت
`coverage = {patch: 1}` بلا اختبار = رقم غير مُثبَت.
| القبول | الرقم |
|---|---|
| تعديل سطر | diff صحيح + `sha256` الأصل ثابت + `.new` مختلف |
| `coverage['patch']` | **≥ 2** |

**بوابة C:** `{compile:≥1, inspect:8, patch:≥2, query:1, render:3, slice:≥5}`.
