# خطة الأدوات المتخصصة المجانية أولاً

هذه خريطة تنفيذ تدريجية للمستودع، وليست ادعاءً بأن النظام يضاهي Claude أو Manus. النجاح في اختبارات الوحدات لا يثبت جودة التفكير أو قابلية استخدام المنتج. لا نضيف أداة جديدة لمجرد تغيير الاسم: نبدأ بالموجود ونثبته ونطوّره. تعني «مجانية أولاً» عدم اشتراط اشتراك مدفوع في المسار المحلي، لا انعدام تكلفة الجهاز والكهرباء ولا ضمان حصص الخدمات الخارجية أو حقوق كل نموذج.

## الموجود الذي يُعاد استخدامه

| المهمة | نقطة البداية | حدّ الدليل |
|---|---|---|
| تنفيذ موثق وسياسات | `projects/agi-system/`, `live-agent/` | تشغيل النواة لا يثبت جودة نموذج لغوي |
| تنسيق المهام والتعافي | `fleet-2027/` | راجع اختباراته؛ لا تفترض أنه موزّع |
| بوابة النموذج والواجهة | `python-2027/`, `workspace-ui/` | المسار المحلي يتطلب نموذجًا وخادمًا وعتادًا متاحًا |
| ذاكرة واسترجاع | `memory/` | التحقق من النتائج والخصوصية والتقييم الدلالي ما زال مطلوبًا |
| أدوات وموصلات ومتصفح | `connectors-hub/`, `browser_skill_adapter/` | لا يعني وجود المجلد اختبار خدمة حقيقية أو صلاحية الاتصال |
| جرد الأخطاء | `tools/repo_doctor.py` و `tools/REPO_DOCTOR.md` | يفحص عددًا محدودًا من الصيغ؛ لا يقرأ سجلات CI |
| قياس الجودة | `fleet-2027/bench/`, `docs/QUALITY-BASELINE.md` | نتائج الوثائق التاريخية لا تثبت حالة اليوم |

اقرأ أيضًا `docs/AI-2027-COMPETITIVE-ARCHITECTURE.md` كجرد تاريخي لا كضمان للحالة الحالية. مشاريع `projects/` أرشيفات متفاوتة الترخيص والحالة؛ راجع الترخيص قبل إعادة الاستخدام.

## ترتيب التنفيذ وقبول كل مرحلة

1. **استعادة خط الأساس:** طابق `catalog.json` مع محتويات الأرشيف، شغّل اختبارات Command HUD وبوابات النشر، وسجّل الفشل الحقيقي بدل تغيير الاختبارات لإخفائه. القبول: تطابق الأعداد في نسخة نظيفة، والبوابات تمر أو يكتب سبب تعذرها.
2. **مهمة واحدة من البداية للنهاية:** نقطة بداية منفذة: `python3 tools/arabic_task_demo.py` تنفّذ مهمة عربية ثابتة وحتمية على مستودع مؤقت تنشئه بنفسها، وتعرض diff واختبارًا وبصمة مستقلة. `--cancel` يلغي قبل التنفيذ. اختبرها بـ `python3 -m unittest discover -s tools -p 'test_arabic_task_demo.py'`. لا تقبل هذه التجربة طلبات عامة أو مسارات مستخدم أو نموذجًا، وليست عزلًا أمنيًا لتشغيل كود غير موثوق؛ لا تطبق شيئًا على مستودع المستخدم. توجد أيضًا معاينة لاستبدال نصي محدد في مساحة يختارها المستخدم: `tools/task_proposal.py`، مع تطبيق اختياري بعد الموافقة وإعادة التحقق من البصمة (التفاصيل والقيود في `tools/TASK_PROPOSAL.md`). هذا التطبيق لمساحة موثوقة فقط، لا يمنع كل السباقات، ولا يوفّر تراجعًا تلقائيًا أو تشغيل اختبارات. **ما زال مطلوبًا:** مسار عام لمهام حرة، وعزل أقوى، واختبارات تكامل وموثوقية إضافية قبل استقبال مهام حقيقية.
3. **نموذج محلي مجاني أولاً:** نقطة بداية اختيارية في `tools/local_task_planner.py` (شرحها `tools/LOCAL_TASK_PLANNER.md`): يرسل مهمة وملفًا إلى Ollama محلي بعد موافقة، ويعيد مقترحًا فقط؛ عند غياب الخادم يُبلغ `BLOCKED`. توجد اختبارات محاكاة، لكن لم يُختبر نموذج حي هنا. ما زال مطلوبًا: قياس الجودة الفعلية، وتوثيق نسخة النموذج والأجهزة والوقت، وتجربة حقيقية اختيارية دون كشف الأسرار.
4. **تقييم فكري وتنفيذي:** مجموعة مهام محفوظة للبرمجة والبحث والعربية والأدوات والتعافي، مع معيار تحقق مستقل، ونتائج قابلة لإعادة الإنتاج. المقارنة بمنتج آخر لا تُنشر إلا عند تشغيل الطرفين على نفس المهام وتوثيق الظروف والقيود. لا استنتاج بالتفوق من عينة صغيرة.
5. **أدوات متخصصة آمنة:** وسّع الأدوات الحالية تباعًا (تشخيص CI، كود، ملفات، بحث، متصفح، مستندات). لكل أداة عقد إدخال/إخراج، حدود موارد وصلاحيات، حالات رفض، واختبارات وحدات وتكامل. استخدام الشبكة والوصول للملفات الخارجية والعمليات المدمرة يتطلبان بوابات واضحة وموافقة.
6. **موثوقية ومراقبة:** استعادة المهمة بعد انقطاع العملية، منع تكرار الآثار الجانبية، تسجيل الأحداث بدون أسرار، وفصل محاكاة المتصفح عن تجربة حقيقية. القبول: اختبار تعافٍ وفشل مقصود وتدقيق للآثار.

## قواعد التكلفة والأمان

- الاعتماد على أدوات محلية ومفتوحة المصدر حيث تسمح التراخيص؛ افحص ترخيص كل نموذج وأداة قبل التوزيع أو الاستخدام التجاري.
- النموذج المحلي قد يحتاج تنزيل أوزان وRAM/GPU؛ الخدمات المجانية الاختيارية قد تتغير حصصها أو شروطها. لا ضمان لمنافسة النماذج التجارية أو أداء مجاني على كل الأجهزة.
- لا ترسل الشيفرة أو البيانات أو الأسرار إلى مزود خارجي دون موافقة صريحة، ولا تعتبر صلاحيات subprocess بديلًا عن عزل نظام تشغيل حقيقي.
- صنّف كل نتيجة `PROVEN` فقط عند وجود اختبار وأثر قابل للتحقق؛ وإلا اذكر أنها خطة أو محاكاة أو محجوبة. لا تُنشأ Issues ولا تُجرى عمليات دمج أو نشر تلقائيًا.
