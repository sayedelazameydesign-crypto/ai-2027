# خطة التشغيل الصفري والربح — Zero-Cost, Revenue-First

> المبدأ الحاكم: **لا يُدفع قرش قبل أن يدخل قرش.** كل مكوّن مجاني دائم، وكل تكلفة مستقبلية تُخصم من إيراد فعلي.

## 1. البنية المعتمدة (بعد التصحيح الهندسي)

```
┌──────────────────────────────────────────────────────────┐
│  تطبيق واحد: Next.js (واجهة + API + SSE في عملية واحدة)  │
│  ├─ LLM: Groq (مجاني، بلا بطاقة، ~14,400 طلب/يوم)        │
│  ├─ DB: SQLite على قرص دائم (200GB مجاني)                │
│  └─ استضافة: Oracle Always Free (4 OCPU / 24GB / للأبد)  │
│     SSL: Caddy + Let's Encrypt (مجاني، يتجدد تلقائيًا)    │
└──────────────────────────────────────────────────────────┘
```

**مرفوض هندسيًا:** فصل الواجهة عن الخادم (يكسر in-process SSE)، Render للإنتاج
(قرص غير دائم + نوم 15 دقيقة)، Fly.io (لم يعد مجانيًا فعليًا).

**احتياطي مستقبلي:** Turso (libSQL) بدل SQLite إن فُرضت استضافة بلا قرص — تغيير
driver في Drizzle فقط، صفر تغيير في كود الوكيل.

## 2. حسابات السعة المجانية

| المورد | الحد المجاني | ترجمته لأعمالنا |
|---|---|---|
| Groq | ~14,400 طلب/يوم، 30/دقيقة | كل تشغيلة = نداءان (مخطط+ملخص) → **~7,000 تشغيلة/يوم** |
| Oracle | 24GB RAM | Next.js + chromium + مئات مستخدمين متزامنين |
| القرص | 200GB | ملايين سجلات runs/approvals |

## 3. سلم الإيراد (Monetization Ladder)

| الدرجة | المنتج | السعر | القناة | متى |
|---|---|---|---|---|
| 0 | خدمة يدوية: «أؤتمت لك مهمة» (استخراج بيانات، تقارير، مراقبة) والمنصة هي الأداة والعرض التوضيحي | 500–5,000 جنيه/مشروع | مباشر / InstaPay | **فورًا — قبل أي بنية دفع** |
| 1 | Freemium: 5 تشغيلات/يوم مجانًا | 0 | المنصة نفسها | بعد المصادقة (v2 الميزة 5) |
| 2 | اشتراك أساسي: 100 تشغيلة/يوم | ~$5/شهر | Lemon Squeezy / Paddle (يعملان لمصر كـ Merchant of Record) | بعد الدرجة 1 |
| 3 | احترافي: بلا حد + أدوات حساسة + أولوية | ~$15/شهر | نفسها + Paymob/Fawry محليًا | حسب الطلب |
| 4 | API للمطورين (إعادة بيع القدرة) | pay-per-run | مفاتيح API + عدّاد | عند نضج الطلب |

> **ملاحظة مصر:** Stripe غير متاح — Lemon Squeezy/Paddle يتحصلان عالميًا
> ويحوّلان لك، وPaymob/فوري/InstaPay للسوق المحلي.

## 4. المتطلبات التقنية لكل درجة (خارطة v3)

| الدرجة | يتطلب بناء |
|---|---|
| 0 | لا شيء — المنصة جاهزة الآن |
| 1 | مصادقة + جدول users + عدّاد استخدام يومي (rate limit per user) |
| 2–3 | webhook من Lemon Squeezy يرفع خطة المستخدم + صفحة أسعار |
| 4 | مفاتيح API + محاسبة per-run |

## 5. تسلسل التنفيذ

1. **مفتاح Groq** (دقيقتان، مجاني) → ربط حي → إثبات التخطيط الدلالي → 33/33
2. **حساب Oracle Always Free** → `bash deploy/oracle-setup.sh` (سكربت جاهز في
   المستودع: Node + build + systemd + Caddy/SSL + health check)
3. **أول عرض بيع** (الدرجة 0) بينما أبني الدرجة 1 (مصادقة + عدّاد)
4. ربط الدفع عند أول طلب اشتراك حقيقي — لا قبله

## 6. قاعدة الانضباط المالي

لا يُرقّى أي مكون لمدفوع إلا بشرطين معًا: (أ) الحد المجاني اختُنق فعليًا بمستخدمين
حقيقيين، (ب) الإيراد الشهري يغطي الترقية ×3. حتى ذلك الحين: المجاني يكفي ويفيض.
