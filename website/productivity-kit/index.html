02 / BROWSER SETUP

افصل العمل اليومي عن التجارب

أنشئ ملفَي Chrome مستقلين وراجع صلاحية الوصول إلى المواقع قبل تفعيل كل إضافة.

ملف التطوير اليومي

ابدأ بـ Refined GitHub. أضف Octotree إذا احتجت شجرة للملفات، واقصر الوصول على GitHub حيث تسمح الإضافة. استخدم تكامل GitHub الرسمي لعمل الوكيل على المستودع، لا مشاركة رموز الوصول.

ملف مختبر معزول

ملف بلا مزامنة أو جلسات شخصية. جرّب Ui.Vision على صفحة الاختبار فقط ثم عطّله. BrowserSkill اختياري ومحلي؛ لا تفتح منافذ ولا توصل ملف استخدامك اليومي به.

إلى Arena: شارك النتيجة لا الجلسة

راجع الملخص أو ملف المراجع قبل إرفاقه. لا تشارك خزائن كلمات المرور، ملفات جلسات، روابط اقتران، أو لقطات فيها بيانات حساب. سجلّ الاختبار الذي تنزّله هنا يحتوي على أسماء الاختبارات وحالاتها اليدوية فقط، مع وقت التصدير.
