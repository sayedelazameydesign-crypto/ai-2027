Cela 2027

Autonomous Manus-style agent with an Arabic dark UI: write a goal, watch it plan publicly, execute with coding tools in a Pyodide sandbox, then verify independently. Ships with a clearly-labeled local simulation mode — no API key needed to explore.

CeliaOS · 12pro

A 12-layer Agent OS control plane: latency/memory/planning/tool-use benchmarks, certification gates G0–G15 with raw evidence artifacts, attestation supply chain, and a monorepo (api + web + agent-ui) certified on Node 24.

A pure-Python AGI kernel with zero dependencies: Goal → Planner → Policy → Executor → Verifier → Evidence → DecisionRecord → EventLedger. 86 unit tests. The Verifier never trusts the Executor.
