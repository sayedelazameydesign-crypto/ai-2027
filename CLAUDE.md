# CLAUDE.md — Compatibility Shim

This file exists so that coding agents that look for `CLAUDE.md` land on the
correct instructions. **The canonical instructions are in
[`AGENTS.md`](AGENTS.md).**

Read `AGENTS.md` first and follow it. The rules are intentionally not
duplicated here: two copies drift, and a drifted rule is worse than no rule.

- Coding-agent instructions → `AGENTS.md`
- Engineering standards → `docs/agent/ENGINEERING-STANDARDS.md`
- Cognitive architecture → `docs/agent/COGNITIVE-ARCHITECTURE.md`
- Runtime operating mind → `prompts/agent/`
- Model capability profiles → `config/routing_profiles.yaml`
