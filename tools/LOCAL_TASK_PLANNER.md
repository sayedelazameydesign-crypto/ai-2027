# اقتراح مهمة عبر نموذج محلي اختياري

`local_task_planner.py` يطلب من خادم Ollama يعمل على `127.0.0.1` اقتراح استبدال نصي واحد، ثم يمرر النتيجة إلى `task_proposal.py` للمعاينة فقط. لا يطبق التعديل ولا يشغّل أوامر أو اختبارات، ولا يتصل بخدمة مدفوعة أو يعود إلى نموذج بديل عند الفشل. **لم يُختبر نموذج حي في هذه البيئة**؛ تستخدم اختبارات الاستجابات خادمًا محاكى، بما في ذلك اختبار HTTP محلي فعلي يختبر المعاينة ثم تطبيقًا منفصلًا بموافقة على ملف مؤقت ورفض إعادة التوجيه.

## المتطلبات والموافقة

اختبارات الملفات الحالية على Ubuntu/Linux فقط؛ Windows الأصلي غير مدعوم، وقد تعمل الأداة داخل WSL مع إمكانات Linux المطلوبة لكن WSL لم يُختبر هنا. راجع [حدود المنصة](TASK_PROPOSAL.md).

ثبّت وشغّل Ollama ونموذجًا متوافقًا محليًا بنفسك، وافحص ترخيص النموذج وتكاليف الجهاز والكهرباء. تنزيل النموذج قد يحتاج إنترنت ومساحة وذاكرة؛ لا تضمن الأداة جودته. الاتصال بخادم loopback لا يثبت أن الخادم نفسه لا يرسل بيانات للخارج؛ تأكد من إعداده وأنه نموذج محلي موثوق. تمرير `--allow-local-model` موافقة صريحة على إرسال **نص المهمة ومحتوى الملف كاملًا** إليه. لا ترسل ملفات سرية. الأداة ترفض بعض أسماء الملفات الحساسة والروابط الرمزية، لكنها لا تكتشف جميع الأسرار.

## الاستخدام

```sh
printf '%s\n' '{"task":"أصلح دالة الجمع","path":"example.py"}' | \
  python3 tools/local_task_planner.py --root /path/to/workspace \
    --model installed-model-name --allow-local-model
```

استبدل اسم النموذج باسم مثبت لديك. يمكن تحديد `--port`، أما المضيف فهو ثابت على `127.0.0.1`. دون الموافقة أو عند تعذر الاتصال/عدم وجود النموذج تكون النتيجة `BLOCKED` ورمز الخروج 2. الملف يجب أن يكون UTF-8، بحجم لا يتجاوز 16 KiB، داخل المساحة المحددة.

النتيجة الناجحة `proposal_only` وتتضمن `request_for_review` و`preview.diff` و`preview.proposal_id`. خرج النموذج غير موثوق: قد يكون خاطئًا أو متأثرًا بمحتوى الملف، حتى إن طابق الشروط الشكلية. راجع الفرق واختبره قبل الاستخدام. إذا أردت تطبيقه، أرسل `request_for_review` يدويًا إلى `task_proposal.py --apply` مع `proposal_id` وبعد قراءة [قيود التطبيق](TASK_PROPOSAL.md). لا يعد التأكيد إثبات هوية، ولا يشغّل الاختبارات أو يوفر تراجعًا تلقائيًا. ترفض الأداة النتيجة إذا تغير الملف أثناء انتظار النموذج.

## قياس أولي محدود

بعد تثبيت نموذج محلي وتشغيله، يمكن تجربة ثلاث مهام ثابتة في ملفات مؤقتة، دون تنفيذ الشيفرة المقترحة:

```sh
python3 tools/evaluate_local_planner.py --model installed-model-name --allow-local-model
python3 -m unittest discover -s tools -p 'test_*.py' -v
```

يسجل التقرير اسم النموذج المطلوب ونظام التشغيل ومعمارية الجهاز وإصدار Python وعدد المعالجات المنطقية والزمن المنقضي لكل حالة؛ الزمن يشمل الطلب والمعاينة وليس زمن استدلال النموذج وحده. لا يتحقق حاليًا من إصدار النموذج أو ذاكرته أو GPU، ويصرّح بذلك صراحة. يقارن التقييم النتيجة بالنص المتوقع حرفيًا أو بشجرة صياغة Python مماثلة، دون تنفيذ الشيفرة. تجاهل التنسيق لا يثبت صحة السلوك؛ وقد يرفض حلولًا صحيحة مختلفة بنيويًا. هذه عينة صغيرة وليست قياسًا شاملًا لجودة التفكير أو مقارنة بمنتج آخر. إذا غاب الخادم أو النموذج تكون النتيجة `BLOCKED` ولا تُحتسب الحالات المتبقية نجاحًا. اختبارات CI تستخدم استجابات نموذج محاكاة، ولا تُثبت تشغيل نموذج حقيقي.
