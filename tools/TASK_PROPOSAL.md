# معاينة وتطبيق تعديل بموافقة صريحة

`task_proposal.py` ينفّذ استبدالًا نصيًا محددًا فقط، وليس وكيلاً لغويًا أو منصة عزل. يعمل محليًا دون خدمة مدفوعة، ولا يشغّل اختبارات أو شيفرة المشروع. استخدمه فقط في **مساحة موثوقة لا يعدّلها طرف آخر بالتزامن**، واحفظ نسخة احتياطية أو استخدم Git قبل التطبيق.

## 1. المعاينة

```sh
printf '%s\n' '{"path":"example.py","old":"return 0","new":"return a + b"}' | python3 tools/task_proposal.py --root /path/to/workspace
```

تعرض النتيجة `diff` و`proposal_id` وبصمتي المحتوى الأصلي والمقترح. راجع الفرق بنفسك؛ قد يكشف شيفرة أو بيانات حساسة. لا تُعدّ بصمة الاقتراح دليلًا على صحته أو نجاح اختباراته.

## 2. الموافقة والتطبيق

بعد مراجعة الفرق، أعد إرسال **الطلب نفسه** مع المعرّف الظاهر في المعاينة:

```sh
printf '%s\n' '{"path":"example.py","old":"return 0","new":"return a + b"}' | python3 tools/task_proposal.py --root /path/to/workspace --apply PROPOSAL_ID
```

استبدل `PROPOSAL_ID` بالمعرّف الفعلي. تمرير `--apply` هو الموافقة الصريحة المحلية؛ لا يثبت هوية الشخص. تعيد الأداة حساب المعاينة والبصمات وترفض المعرف القديم إذا تغيّر الملف أو الطلب أو مساحة العمل. `--confirm PROPOSAL_ID` يبقى متاحًا للتأكيد **من دون كتابة**. رمز الخروج 0 عند النجاح و2 عند رفض الطلب؛ `tests_run` يظل `false`.

تكتب الأداة ملفًا مؤقتًا في المجلد نفسه، ثم تستبدل الملف الذري بعد إعادة فحص حالته؛ تحافظ على بتات الصلاحيات العادية وترفض الروابط الصلبة والرمزية والملفات غير العادية. إذا فشل الاستبدال قبل اكتماله، يبقى الأصل وتُحذف النسخة المؤقتة متى أمكن. **لا يوجد تراجع تلقائي بعد التطبيق**؛ استعد النسخة من Git أو نسخة احتياطية إذا لم تكن النتيجة مناسبة. قد لا تُحفظ الملكية أو ACL أو السمات الممتدة أو الطوابع الزمنية؛ لا تستخدمها إن كانت هذه البيانات مهمة. لا يُضمن استمرار التعديل بعد انقطاع مفاجئ للطاقة.

لا يمثل الفحص والاستبدال عملية مقارنة وتبديل ذرية واحدة: قد يكتب طرف آخر بين الفحص والاستبدال. لا تستخدم الأداة مع كتّاب متزامنين أو في مجلدات غير موثوقة. `O_NOFOLLOW` ورفض اجتياز المسارات يقللان المخاطر لكنهما ليسا عزل نظام تشغيل أو حماية شاملة للأسرار.

## الاختبارات

```sh
python3 -m unittest discover -s tools -p 'test_task_proposal.py' -v
```

تختبر المعاينة والتطبيق والموافقة القديمة والروابط الرمزية والصلبة وفشل الاستبدال والتغيير أثناء التحضير. لا تغطي جميع سيناريوهات السباق أو أعطال النظام. أداة `arabic_task_demo.py` منفصلة وتنفذ مثالًا ثابتًا موثوقًا في مستودع مؤقت؛ لا تمرّر لها شيفرة غير موثوقة.
