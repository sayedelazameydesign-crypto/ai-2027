# اقتراح تعديل للقراءة فقط

أداة `task_proposal.py` خطوة وسيطة لتجهيز تعديل حقيقي للمراجعة البشرية، **وليست وكيلاً لغوياً أو منصة عزل**. تقبل مسار ملف UTF-8 واستبدالاً نصياً صريحاً، وليس طلباً عربياً حراً، ولا تغيّر أي ملف ولا تنفذ اختبارات أو أوامر داخل مساحة العمل. تعرض diff وبصمتي النص قبل التعديل وبعده؛ البصمة الثانية محسوبة من النص المقترح وليست دليلاً على تطبيقه أو صحته.

```sh
printf '%s\n' '{"path":"example.py","old":"return 0","new":"return a + b"}' | python3 tools/task_proposal.py --root /path/to/workspace
python3 -m unittest discover -s tools -p 'test_task_proposal.py' -v
```

بعد مراجعة diff، يمكنك إعادة إرسال الطلب نفسه وتمرير قيمة `proposal_id` المعروضة عبر `--confirm PROPOSAL_ID`. تعيد الأداة قراءة الملف وتطابق معرّفًا مرتبطًا بمساحة العمل والمسار وبصمتي النسختين؛ ترفض التأكيد إذا تغير الملف أو الاقتراح. التأكيد محلي وغير موثّق الهوية، **ولا يطبق التعديل ولا يشغّل اختبارًا** ولا يصلح تفويضًا دائمًا؛ يجب إعادة التحقق عند أي تنفيذ مستقبلي.\n\nيرفض المسارات المطلقة أو `..` والروابط الرمزية ومكونات `.git` وأسماء أسرار شائعة، والملفات غير العادية أو الأكبر من 256 KiB، والتطابق المفقود أو المتكرر. يستخدم فتح المسار مكونًا بمكون عبر `O_NOFOLLOW`؛ يرفض التشغيل إذا لم تدعم المنصة ذلك. هذا دفاع محدود وليس عزل نظام تشغيل؛ لا يحمي من كل الملفات الحساسة أو الوصلات الصلبة، ولا ينبغي استخدامه على مساحة غير موثوقة. اسم الملف وdiff قد يكشفان شيفرة أو أسرارًا، فراجعهما قبل المشاركة. يمكن مراجعة المقترح وتطبيقه يدويًا، ثم تشغيل الاختبارات في بيئة مناسبة وآمنة.

أداة العرض الحتمي المنفصلة `arabic_task_demo.py` تنشئ مستودعًا مؤقتًا وتنفذ مثالًا ثابتًا موثوقًا؛ لا تمرّر لها كودًا من مستخدمين ولا تعاملها كبيئة معزولة.
